# 🚧 Principales Dificultades 
---
Durante la unidad 2 se logro acercar a estructuras condicionales y repetitivas, aumentando el progreso y la complejidad con cada acercamiento relacionado programacion, mediante el aprendizaje de estas estrucuras presente ciertas dificultades en la logica de como aplicarlas, que se debe saber utilizar cada elemento de manera correcta.

Donde presente mayor dificultad fue en las estructuras repetitivas, ya que necesitan una aplicacion logica y concreta para usarlos, utilizando lo que son contadores y acumuladores para poder repetir cierta cantidades de veces , lo que aumenta la complejidad de desarrollo de algoritmos. Presentando varios errores respecto al desarrollo de estructuras repetitivas, a su estructura ya que los varios ejercicios necesitan utilizar expresiones matematicas utilizando estructuras repetitivas logicas y simplificadas, que cumplan una condicion.

Ademas en esta unidad se acerco a otros lenguajes de progrmacion donde se presento cierta complejidad en Java, ya que java al ser un lenguaje de programacion orientado a objetos, es diferente al desarrollo de codigo del lenguaje de programacion que se ha desarrollado como es el lenguaje C, al momento de utilizar Java existe otras reglas y sintaxis que son necesarias para ejecutar un programa, siendo un verdadero reto al principio para lograr ejecutar comandos en este lenguaje de programacion.
